# 🥛 Dairy Taluka Executive Dashboard

![Dashboard Preview](dashboard-preview.png)

## 🚀 Project Overview

This project is an advanced **Dairy Taluka Analytics Dashboard** developed using:

- 📊 Excel Dashboarding
- 📈 Interactive HTML Dashboard
- 📉 Business Analytics
- 🧾 Dairy Sales & Profit Analysis

The dashboard helps analyze dairy business performance across multiple talukas with detailed insights into:

- Total Sales & AMC
- Profit vs Loss Analysis
- Taluka-wise Dairy Distribution
- Monthly Sales Tracking
- Top Performing Sansthas
- Cumulative Dairy Contribution

## 📷 Dashboard Features

### 1️⃣ Profit vs Loss Analysis
Interactive donut chart comparing:
- Overall Profit
- Pending Loss

### 2️⃣ Taluka Distribution
Visual breakdown of dairies across talukas:
- Karveer
- Radhanagari
- Kagal
- Hatkanangale
- Bhudargad
- Goa
- Panhala
- Chandgad

### 3️⃣ Monthly Sales Tracking
Bar chart visualization for:
- Sales Performance
- Profit Trends
- Pending Status

### 4️⃣ Top Performing Sansthas
Top 10 dairy sansthas ranked by sales amount.

### 5️⃣ Cumulative Contribution Analysis
Pareto-style cumulative percentage analysis of dairy distribution.
